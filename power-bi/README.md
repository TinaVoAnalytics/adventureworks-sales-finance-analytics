# Power BI Dashboard

This folder contains the interactive Power BI report developed for the AdventureWorks Sales Finance & Profitability Analytics project.

## Dashboard Pages

1. Executive Overview
2. Pricing & Profitability
3. Territory & Reseller
4. Product Profitability

The report uses DAX measures, comparable-period analysis, slicers, bookmarks, field parameters, dynamic metric selection, report-page tooltips, and drill-through analysis to support profitability monitoring and diagnostic investigation.

## Power BI File

`AdventureWorks_Sales_Profitability_Analysis.pbix`

> Download the PBIX file to explore the complete interactive dashboard in Microsoft Power BI Desktop.
